## Link para API
http://15.229.153.72/imoveis


## Rotas
- `GET /imoveis` — lista todos os imóveis
- `GET /imoveis/<id>` — busca um imóvel por id
- `POST /imoveis` — adiciona um imóvel
- `PUT /imoveis/<id>` — atualiza um imóvel
- `DELETE /imoveis/<id>` — remove um imóvel
- `GET /imoveis/tipo/<tipo>` — busca por tipo
- `GET /imoveis/cidade/<cidade>` — busca por cidade
